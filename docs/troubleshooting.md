## Чашки не видно в меню-баре

На Mac с вырезом камеры значки, которым не хватило места, оказываются под вырезом.

- Запусти «Бодрячок» ещё раз из «Программ» или через Spotlight. Меню откроется под курсором.
- Освободи место в меню-баре: закрой лишние программы со значками или убери ненужные значки, перетащив их из меню-бара с зажатой ⌘.
- Когда чашка появится, её можно перетащить на удобное место с зажатой ⌘.

Проверить, что приложение запущено:

```bash
pgrep -x Bodryachok
```

Если команда ничего не вывела, приложение не работает.

## Mac всё равно засыпает с закрытой крышкой

Проверь по порядку.

1. **Рядом с чашкой есть значок `⌄`?** Режим действует, только когда он есть. Без него Mac уснёт.
2. **Идёт ли сессия?** Чашка должна быть закрашена. Режим крышки работает только во время сессии.
3. **Стоит ли галочка «Не спать с закрытой крышкой»?**
4. **Включена ли настройка «Крышка — только от сети»?** С ней режим не работает от батареи.
5. **Не было ли перегрева?** Если в меню есть строка «Крышка: выключено в … из-за перегрева», режим выключен до конца сессии. Запусти сессию заново.
6. **Не упал ли заряд ниже порога?** Тогда сессия завершилась, и в меню осталась строка с причиной.

Проверить системную настройку напрямую:

```bash
pmset -g | grep SleepDisabled
```

Во время сессии с режимом крышки должно быть `1`.

## Mac засыпает с открытой крышкой

Проверь, что сессия идёт и приложение держит запрет сна:

```bash
pmset -g assertions | grep Bodryachok
```

Если строк нет, сессия не запущена. Если строки есть, а Mac засыпает, причина в другом: приложение не отменяет сон, который включают вручную (меню Apple → «Режим сна»), кнопкой питания или при критически низком заряде.

## Экран блокируется

Работу это не останавливает: блокируется только экран, программы продолжают работать.

- **При закрытии крышки.** Это делает сам «Бодрячок», чтобы работающий ноутбук нельзя было открыть без пароля. Отключается в «Настройки → Блокировать экран при закрытии крышки».
- **После отключения этой настройки экран всё равно блокируется.** Это делает macOS: при закрытой крышке дисплей гаснет, а пароль после выключения дисплея система требует по своим настройкам. Интервал меняется в «Системные настройки → Экран блокировки».
- **При открытой крышке, пока Mac не трогают.** Проверь, не включён ли пункт «Разрешить сон экрана»: с ним экран гаснет и блокируется как обычно.

## Сессия сразу завершается

Скорее всего, Mac работает от батареи, и заряд ниже порога. При ручном запуске приложение показывает об этом окно с кнопкой «Запустить всё равно». Порог меняется в «Настройки → Завершать при заряде ниже», вариант «Никогда» его отключает.

Если включено «Включать сессию при запуске», а заряд ниже порога, автозапуск пропускается без окна. В меню остаётся строка «Автозапуск пропущен: …».

## Сессия закончилась, пока я был в дороге

Открой меню чашки. Под статусом будет причина и время:

| Строка в меню | Что произошло |
|---|---|
| Сессия завершена в …: заряд ниже N% | сработал порог заряда |
| Сессия завершена в …: время вышло | закончился таймер |
| Сессия завершена в …: приложение «…» закрылось | закрылась программа, за которой следила сессия |
| Крышка: выключено в … из-за перегрева | macOS сообщила о перегреве, режим крышки выключился, Mac уснул |

Что помогает доехать с работающим ноутбуком: режим энергосбережения, отсутствие чехла, закрытые лишние программы и достаточный заряд.

## Mac перестал засыпать вообще

Так бывает, если системный запрет сна остался включённым. Приложение возвращает его само несколькими способами, но проверить и исправить можно вручную.

Проверить:

```bash
pmset -g | grep SleepDisabled
```

Если там `1`, а сессии нет, верни сон:

```bash
sudo pmset -a disablesleep 0
```

Если значение `0`, а Mac не засыпает, дело не в «Бодрячке». Посмотри, какие программы держат запрет сна:

```bash
pmset -g assertions
```

## Режим крышки не включается

- **Окно пароля закрыто кнопкой «Отмена».** Без пароля администратора правило не устанавливается. Поставь галочку ещё раз.
- **Учётная запись без прав администратора.** Нужно ввести имя и пароль администратора этого Mac.
- **Сообщение «Необычное имя пользователя».** Приложение ставит правило только для коротких имён из латинских букв, цифр, точки, дефиса и подчёркивания.
- **Сообщение «Режим закрытой крышки не включился».** Правило есть, но команда не выполняется. Удали доступ в «Настройках» и включи режим заново.

Проверить, что правило на месте:

```bash
sudo -n -l | grep pmset
```

## Приложение не запускается после входа в систему

Настройка «Запускать при входе в систему» может сброситься после пересборки приложения: у новой сборки другая локальная подпись. Открой «Настройки» в меню чашки и поставь галочку заново.

Проверить можно и в «Системные настройки → Основные → Объекты входа».

## Не приходят уведомления

Разрешение на уведомления приложение спрашивает при первом запуске сессии. Если тогда был выбран отказ, вместо уведомления звучит системный сигнал.

Включить: «Системные настройки → Уведомления → Бодрячок».

Причина завершения сессии в любом случае остаётся в меню чашки.

## macOS не даёт открыть приложение

Так бывает с готовой сборкой, полученной с другого Mac: у приложения нет подписи разработчика Apple.

1. Попробуй открыть приложение, в окне с предупреждением нажми «Готово».
2. Открой «Системные настройки → Конфиденциальность и безопасность», прокрути вниз и нажми «Всё равно открыть» рядом со строкой про «Бодрячок».

На macOS 13 и 14 можно проще: правый клик по приложению → «Открыть».

Или сними пометку карантина командой:

```bash
xattr -dr com.apple.quarantine "/Applications/Бодрячок.app"
```

Приложение, собранное на этом же Mac командой `./build.sh --install`, открывается без предупреждений.

## Ноутбук сильно греется

«Бодрячок» сам процессор не нагружает. Греют задачи, которые продолжают работать, пока Mac не спит, и фоновая работа самой macOS: индексация Spotlight, анализ фотографий, синхронизация iCloud, резервные копии.

- Посмотри в «Мониторинге системы» на вкладке «ЦП», что занимает процессор.
- Включи режим энергосбережения в «Системные настройки → Аккумулятор».
- Не держи работающий ноутбук с закрытой крышкой в сумке, на одеяле или в чехле.

## Как убрать всё вручную

Обычный способ описан в разделе [«Удаление»](../README.md#удаление). Команды ниже нужны, если приложение уже удалено, а следы остались.

Вернуть сон, если он остался отключённым:

```bash
sudo pmset -a disablesleep 0
```

Удалить правило sudo:

```bash
sudo rm -f /etc/sudoers.d/bodryachok
```

Остановить и удалить фонового страховщика:

```bash
launchctl bootout gui/$(id -u)/local.bodryachok.failsafe
```

```bash
rm -f ~/Library/LaunchAgents/local.bodryachok.failsafe.plist
```

```bash
rm -rf ~/Library/Application\ Support/Bodryachok
```

Удалить настройки приложения:

```bash
defaults delete local.bodryachok
```
